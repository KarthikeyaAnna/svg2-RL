\section{Overview \& Motivation}
%=====================================================================
Video Scene Graph Generation (VidSGG) requires detecting objects, tracking them, and predicting structured triplets $\langle \text{subject}, \text{predicate}, \text{object} \rangle$ grounded with temporal timestamps $[t_{\text{start}}, t_{\text{end}}]$. 

The released baseline model, \textbf{TraSeR} (based on Qwen2.5-VL-3B with object slot tokens), encounters two major failure modes when generating entire graphs in a single sequence:
\begin{enumerate}
    \item \textbf{Whole-graph salience bottleneck:} Generating all relations autoregressively causes the model to miss over 60\% of interacting pairs due to token caps, loop-prevention truncation, and attention dispersion.
    \item \textbf{Precision and hallucination trade-off:} Naive pair querying (adding candidate object pairs) introduces massive false-positive predicates (added-pair precision is only 11\% on SVG2 and 4\% on PVSG). Standard SFT suffers from format/convention bleed and looping.
\end{enumerate}

To solve this, we developed a two-tier reinforcement learning strategy:
\begin{itemize}
    \item \textbf{Plain G3:} Whole-graph GRPO that aligns the base model autoregressively on training videos, lifting precision, eliminating repetition loops, and increasing recall without formatting bleed.
    \item \textbf{G3 + PG:} A pair-factored architecture that combines G3's primary graph with a specialized pair-level GRPO adapter (\textbf{PG}) trained with explicit abstention rewards on negative candidate pairs.
\end{itemize}

%=====================================================================
\section{Method 1: Plain G3 (Whole-Graph GRPO)}
%=====================================================================

\subsection{Formulation \& Objective}
Plain G3 optimizes the LoRA weights $\theta$ of the language model backbone via Group Relative Policy Optimization (GRPO). For each video $v$, a group of $G=8$ rollouts $\{o_1, \dots, o_G\}$ is sampled under temperature $T=1.0$ and top-$p=0.95$. 

The surrogate loss per group is:
\begin{equation}
\mathcal{L}_{\text{GRPO}}(\theta) = -\frac{1}{G} \sum_{i=1}^G \min \left( \frac{\pi_\theta(o_i|v)}{\pi_{\text{old}}(o_i|v)} A_i, \; \text{clip}\left(\frac{\pi_\theta(o_i|v)}{\pi_{\text{old}}(o_i|v)}, 1-\epsilon, 1+\epsilon\right) A_i \right) + \beta D_{\text{KL}}(\pi_\theta \,||\, \pi_{\text{ref}})
\end{equation}
where advantage $A_i = \frac{r_i - \text{mean}(R)}{\text{std}(R)}$ is normalized strictly within the group of 8 candidate graphs of that video.

\subsection{Reward Function}
The reward $r(o_i, \text{GT}_v)$ is evaluated via \path{engine/reward.py}:
\begin{equation}
r(o_i) = \frac{1}{|\text{GT}_v|} \sum_{(s, p, o, \text{span}) \in \text{GT}_v} \max_{(s', p', o', \text{span}') \in o_i} \mathbb{I}(s=s' \land o=o' \land \text{norm}(p)=\text{norm}(p')) \cdot \text{tIoU}(\text{span}, \text{span}')
\end{equation}
where temporal overlap $\text{tIoU} \ge 0.5$ provides soft fractional credit. Syntactic looping or malformed outputs receive zero reward.

\subsection{Training Hyperparameters}
\begin{itemize}
    \item \textbf{Data:} TraSeR's own SVG2 training splits only (50\% PVD / 50\% VidOR mix; strictly no PVSG-train).
    \item \textbf{Optimization:} AdamW, learning rate $\eta = 3\times 10^{-5}$, linear warmup for 20 steps, total 300 steps ($\sim 5.2$ hours).
    \item \textbf{LoRA Adapter:} Rank $r=16$, $\alpha=32$, applied to attention query/key/value projections in language layers.
    \item \textbf{Batch Size:} 1 video per gradient step ($8$ sampled graphs per step, $G=8$).
    \item \textbf{Training Run:} Single deterministic training run (\path{traser-e1-g3}).
\end{itemize}

\section{Method 2: G3 + PG (Pair-Factored Policy Optimization)}
%=====================================================================

\subsection{Two-Tier Architecture}
\begin{enumerate}
    \item \textbf{Base Stage (G3):} Generates the base scene graph $G_{\text{base}}$ for the full video.
    \item \textbf{Candidate Proposer:} A 11-feature HistGradientBoosting classifier (\path{HistGBM}) scores all unmentioned object pairs based on bounding-box proximity, IoU, relative scale, and visual trajectory overlap. Top candidate pairs with predicted probability $\tau \ge 0.5$ are kept.
    \item \textbf{Pair-Level Decoder (PG):} For each candidate pair $(a, b)$, the video features are sub-selected to only objects $a$ and $b$, and prompted with \path{"scene\_graph"}. The pair-level adapter decodes the predicate and temporal extent.
    \item \textbf{Graph Merging:} Valid decoded pair relationships are deduplicated and merged into $G_{\text{base}}$ via \path{scripts/merge_pairs.py}.
\end{enumerate}

\subsection{PG Training \& The Abstention Reward}
The pair-level policy is trained via GRPO on pairs sampled from training videos. To combat hallucination on unlabelled pairs, the reward includes an explicit \textbf{abstention bonus}:
\begin{equation}
r_{\text{pair}}(y) = 
\begin{cases}
\text{RelationCredit}(y, \text{GT}) & \text{if candidate pair is labelled in GT} \\
0.5 & \text{if pair is an unlabelled hard-negative and model predicts ``none''} \\
0.0 & \text{if pair is an unlabelled hard-negative and model invents a relation}
\end{cases}
\end{equation}
This teaches the model to remain silent on unlabelled pairs while maintaining high recall on true interactions.

\section{Benchmark Results}
%=====================================================================
All metrics are computed using the strict per-span $\text{tIoU} \ge 0.5$ benchmark protocol with the Qwen3-8B lenient judge (SVG2 categories). Statistical significance ($^{\dagger}$) is determined via 2,000-sample paired bootstrap ($p < 0.05$).

\textbf{Key Takeaways:}
\begin{itemize}
    \item \textbf{Plain G3 alone} significantly beats TraSeR on VidOR Precision, Recall, and F1 simultaneously ($+1.1$ F1$^{\dagger}$) and achieves a $+5.7\%$ recall gain on SVG2 without dropping precision.
    \item \textbf{G3 + PG} beats TraSeR on \textbf{Relation Recall and Triplet Recall across all three benchmarks with statistical significance}, and delivers a massive $+3.9$ F1 improvement on VidOR.
\end{itemize}
