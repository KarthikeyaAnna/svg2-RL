\section{Summary}
%=====================================================================
Training-free post-processing on released TraSeR (Qwen2.5-VL-3B); relation P/R/F1.
SVG2test: +40 contact-ranked pair queries, R 24.7$\to$\textbf{43.3}\sig\ (F1 n.s.); contact filter, F1 20.1$\to$\textbf{24.3}\sig.
VidOR-val: the configuration pre-registered from SVG2test is null; an exploratory one (20 pairs + reverse-direction completion)
gives F1 13.9$\to$\textbf{19.1}\sig, but contact ranking does not beat random pairs. PVSG-val: recall up, F1 down\sig. The contact filter helps SVG2test only (PVSG n.s., VidOR F1 $-2.2$\sig).
No single configuration improves all three.

\section{Setup}
%=====================================================================
\textbf{Data.} SVG2test: 67 VIPSeg videos, 66 scored (33 SA-V videos licence-gated, not run). PVSG-val: 62 videos, plus a 27-video clean
subset (35/40 VidOR-sourced PVSG videos are in TraSeR's training set). VidOR-val: 835 videos. GT object masks are given (SVG2 protocol).

\textbf{Systems.} All operate on TraSeR's output and the given GT masks; TraSeR's weights are unchanged.
\begin{itemize}\setlength{\itemsep}{2pt}
\item \textbf{Contact filter.} For every predicted relation (s, p, o), take the two objects' masks on the sampled frames
      (4$\times$ downsampled), dilate one by 2 cells, and test overlap with the other. If they never overlap in any frame, the
      relation is removed. Rationale: SVG2test annotators label 15.4\% of touching vs 0.8\% of non-touching pairs.
\item \textbf{+$K$ salient.} (1) List object pairs that appear in no predicted relation. (2) Score each by the fraction of
      co-visible frames in which the dilated masks touch; keep the top $K$. (3) For each pair, run TraSeR again with only those
      two objects as input (same prompt) and parse the relations it returns. (4) Map them back to the original object IDs and
      append them to the graph; exact duplicates are merged. Rationale: 50\% (SVG2test) / 47\% (PVSG) of all GT relations are
      on pairs TraSeR never mentions (Table~1).
\item \textbf{+20 random.} Steps (1), (3) and (4) with 20 pairs drawn uniformly from the unmentioned pairs: same number of extra
      queries, no contact ranking (control).
\item \textbf{Filter + 20 salient.} Contact filter, then +20 salient.
\item \textbf{Both directions.} For each relation (s, p, o) whose predicate has a known inverse (e.g.\ above $\leftrightarrow$ below,
      in front of $\leftrightarrow$ behind, on $\leftrightarrow$ under, inside $\leftrightarrow$ contains) or is symmetric (next to,
      near, beside), add (o, p$^{-1}$, s) with the same time spans if it is not already present. Rationale: VidOR labels 81\% of
      pairs in both directions, TraSeR 12\%.
\end{itemize}
VidOR-val config (filter + 20 salient) was fixed on SVG2test before any VidOR run.

\textbf{Metric.} Match = same ordered pair, predicate equivalent under a Qwen3-8B judge (SVG2's five categories; stand-in for
GPT-4o-mini), temporal IoU $\geq 0.5$ per span; exact duplicates merged. \sig: paired per-video bootstrap (2000), 95\% CI excludes 0.
